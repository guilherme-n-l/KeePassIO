# Security policy

KeePassIOS stores password databases, so security reports are taken seriously.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue, and don't include a real database, key file or password in the report; a minimal synthetic database that reproduces the problem is ideal.

You'll get an acknowledgement within 7 days. Fixes are released as soon as they're ready, and reporters are credited unless they ask not to be.

## Scope

In scope: the app, its extensions, and the code in this repository. Out of scope: vulnerabilities in iOS itself, and attacks that require an already unlocked, physically compromised device beyond what the threat model in PLAN.md covers.
